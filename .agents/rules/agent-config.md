# Agent configuration

- Canonical sources are hand-edited and live only in `.agents/`: `skills/<name>/SKILL.md` (+ `agents/openai.yaml`, optional `references/`), `agents/<name>.md`, `rules/<name>.md`, `workspace.json`. After any change run `npm run agents:sync` and commit sources and outputs together; `npm run check` runs `agents:check` and fails on drift.
- Generated (carry a "Generated by scripts/agents/sync.mjs" marker; never edit): `.claude/skills/**`, `.claude/agents/*.md`, `.claude/rules/*.md`, `.cursor/rules/*.mdc`, `.github/agents/*.agent.md`, `.github/instructions/*.instructions.md`, `.codex/agents/*.toml`, `.github/copilot-instructions.md`, and the `agents:skills`, `agents:agents`, `agents:rules` regions of `AGENTS.md`.
- Hand-written: `AGENTS.md` outside the generated regions (≤ 160 lines), `CLAUDE.md` (`@AGENTS.md` plus Claude-only notes), `.agents/README.md`, `.claude/settings.json`, `.cursor/worktrees.json`, `.worktreeinclude`. The `agents:essentials` region of `AGENTS.md` is copied verbatim to Copilot: use code paths there, not relative links.
- Skills: folder name = `name` (`a-z0-9-`, ≤ 64, `site-` prefix); `description` ≤ 1024 chars, starts with an imperative verb, says what and when with trigger words; optional `paths`, `argument-hint`, `disable-model-invocation`, `metadata`; no `allowed-tools`. Body ≤ 400 lines of concrete commands, decision tables and a "Done when" checklist.
- Agents: `name`, `description`, `tools` ⊆ read, search, edit, execute, web, agent; `model-tier` ∈ inherit, fast, balanced, strong; `readonly`; optional `skills`. Body: role, inputs, procedure, output contract; never contains three consecutive single quotes (Codex TOML).
- Rules: `description`, `paths` (comma-separated globs) unless `alwaysApply: true`; body ≤ 60 lines of invariants.
- State the autonomy policy once, in `AGENTS.md`; skills and agents reference it instead of restating it.
- `.claude/settings.json`: hooks call the vendored `scripts/agents/hooks/*.mjs`; the `deny` list for secret files and the `ask` list for force pushes, tag deletion, workflow dispatch and releases must not be weakened.
- Platform documentation and the generator, hooks and worktree scripts are upstream in the extension repo; change them there and re-vendor (`.agents/README.md`).
- Verify: `npm run agents:check`, `npm test`, `npx prettier --check .agents AGENTS.md CLAUDE.md .claude`.
