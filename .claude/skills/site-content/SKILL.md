# Claims and privacy review

The site is the public promise for a product that handles tab audio and the user's own Gemini key. Copy must say only what the extension verifiably does, in the extension version the copy names.

## 1. Collect the diff and sources

```sh
git fetch origin
git diff origin/main...HEAD -- src/pages.mjs site.config.mjs scripts/generate-social-card.mjs README.md
SITE_MAIN="$(dirname "$(git rev-parse --path-format=absolute --git-common-dir)")"
EXT="$(dirname "$SITE_MAIN")/Realtime-Dubbing"
LIVE="$(node --input-type=module -e "import { site } from './site.config.mjs'; console.log(site.extensionVersion)")"
git -C "$EXT" fetch origin --tags
git -C "$EXT" show "v$LIVE:apps/extension/privacy.html"     # behaviour users run today
```

For copy about a candidate release, read the same files at the candidate ref (`origin/release/<x.y.z>`) as well. Extension sources of truth: `apps/extension/privacy.html`, `docs/PRIVACY.md`, `docs/release/RELEASE-<x.y.z>.md`, `docs/release/chrome-store/privacy-practices.md`, manifest permissions in `apps/extension/vite.config.ts`. The hub `PRODUCT.md` is an internal brief; its wording (for example "BYOK", "zero server-side retention") is not approved public copy.

## 2. Automated floor

```sh
npm run build && node scripts/check.mjs
grep -r -n -i -o -E "\bBYOK\b|100% secure|zero latency|millisecond translation|unlimited dubbing|trusted by [0-9]|Realtime Dubbing" src/
```

`scripts/check.mjs` fails the build on `\bBYOK\b|100% secure|zero latency|millisecond translation|unlimited dubbing|trusted by \d` (case-insensitive) and on the retired brand "Realtime Dubbing" anywhere in `dist/`. Passing it is necessary, not sufficient. When review finds a new phrase that must never ship, add it to that regex in the same PR; never remove or loosen an entry.

## 3. Claim rules

| Topic                    | Allowed                                                                                  | Not allowed                                                                           | Evidence required                                                |
| ------------------------ | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Speed and sync           | "translation needs processing time", delayed sync window, catch-up limits disclosed      | instant, zero latency, millisecond, "real time" without a delay caveat                | Any number needs the extension's latency corpus with p50/p95/p99 |
| Languages                | `${languageCount}` Gemini Live Translation languages, "provider-documented"              | quality guarantees, "every language", hardcoded counts                                | `src/languages.json` and its Google source                       |
| Version and availability | `site.extensionVersion` with the store links in `site.stores`                            | dates for unreleased versions, Firefox/Safari/mobile availability, "coming soon"      | Anonymous listing check (site-deploy §5)                         |
| Security and privacy     | concrete mechanism and its limit (AES-GCM record in profile IndexedDB, same-profile key) | "100% secure", "military-grade", "never leaves your device", "we never see" absolutes | Extension privacy page and `docs/PRIVACY.md` at that version     |
| Cost                     | "Google API fees may apply", user's own Gemini key, Never-stop cost warning              | free, unlimited, "no costs"                                                           | Google pricing link                                              |
| Compatibility            | websites with accessible media in desktop Chrome and Edge; DRM/protected-stream limits   | "every website", "all videos", bypass claims                                          | Extension compatibility docs                                     |
| Social proof             | none                                                                                     | "trusted by N", ratings, testimonials, press logos                                    | —                                                                |
| Affiliation              | "Independent project. Not affiliated with Google, Microsoft or media websites."          | implied endorsement, store badges not issued by the store                             | —                                                                |
| Key wording              | "your own Gemini API key"                                                                | "BYOK"                                                                                | —                                                                |

## 4. Privacy parity

Map each extension disclosure to the site. Site privacy sections live in the `privacy` template of `src/pages.mjs`.

| Extension (privacy.html section / file)                  | Site location                                                                                    |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| "What happens when you start"                            | privacy §2 What happens when you start dubbing; guide "Open a tab. Choose a language. Start."    |
| "What stays on your device"                              | privacy §3 Credentials and local preferences, §4 Audio, picture and caption buffers              |
| "Control and deletion"                                   | privacy §5 Exports and deletion                                                                  |
| "Services and limits"                                    | privacy §2 (Google processing), support "Provider access and charges", terms "Provider accounts" |
| `docs/PRIVACY.md`, `privacy-practices.md`                | privacy §2–§5 must not contradict them                                                           |
| Manifest permissions and host origins (`vite.config.ts`) | privacy §2–§3, guide install step                                                                |

Checklist per version:

- [ ] Every data item the extension sends (selected-tab audio, language, key use) and the endpoint it goes to is disclosed.
- [ ] Every locally stored item (key record, preferences, per-site settings) is disclosed with scope and how to delete it.
- [ ] Buffers are described as bounded and in memory where the extension says so; exports name the formats the extension offers.
- [ ] Renamed features use the extension's current names (grep the old phrase in `src/pages.mjs`).
- [ ] Privacy "Last updated <Month D, YYYY>" (privacy intro) moved when privacy content changed; terms likewise.
- [ ] Version-specific behaviour is labelled ("Version 0.2.18 and later …") while older versions remain live.

## 5. Report

Severity: **blocker** — privacy behind the extension version being submitted or live, banned or absolute claim, version/availability without a verified listing, new external request or third-party asset; **major** — missing limitation (fees, delay, DRM), stale feature name, missing "Last updated" bump; **minor** — tone, clarity.
